# Brand Book — Anclora Group

**Versión:** 2.0 (definitiva)

---

## 1. Propósito del documento

Este brand book es la **fuente única de verdad** de la identidad de **Anclora Group**, marca matriz del ecosistema Anclora. Consolida:

1. El sistema estratégico y verbal validado (posicionamiento, voz, arquitectura de marca).
2. La paleta resuelta conforme al Skill Máster Definitivo Anclora v4.1.
3. El sistema de logo completo (medalla + lockups + monocromos + favicons).
4. Tokens de diseño implementables (color, tipo, espaciado, radio, movimiento) para la landing en `anclora.com`.
5. Copy base y estructura recomendada de la landing.

Debe usarse como referencia para diseño, desarrollo, comunicación pública y cualquier pieza corporativa del grupo.

---

## 2. Esencia y posicionamiento

**Esencia:** Anclora Group es una marca tecnológica founder-led que diseña, valida y opera productos digitales propios orientados a reducir fricción operativa, mejorar decisiones y transformar procesos complejos en sistemas claros, útiles y escalables.

La marca debe transmitir: `claridad · control · inteligencia aplicada · dirección · confianza · ejecución`.

**Posicionamiento principal:**

> Anclora Group es una boutique tecnológica founder-led que crea productos digitales premium para fiscalidad, automatización, inteligencia inmobiliaria, eficiencia, contenido y operaciones empresariales.

**Tagline oficial (ES):**

> Tecnología aplicada para operar con más claridad, control e inteligencia.

**Versión hero:**

> Productos digitales para convertir procesos complejos en sistemas claros, útiles y escalables.

**Versión internacional:**

> Digital products for clearer operations, smarter decisions and scalable systems.

El ángulo fuerte no es «hacemos IA». El ángulo fuerte es: **construimos sistemas digitales claros para operar mejor.**

Los favicons se derivan de la medalla por reducción directa (recorte al bounding box + LANCZOS), sin rediseño. El trazo metálico (ring + ondas) permanece legible a 32px.

**Composición del lockup:**

```text
Wordmark: "Anclora Group" — DM Sans ExtraBold (peso 800).
Alineación horizontal: medalla a la izquierda, wordmark centrado verticalmente a su derecha.
Alineación vertical: medalla centrada arriba, wordmark centrado debajo.
Color de wordmark: White Deck (#F8FAFC) sobre fondos oscuros · Anchor Navy (#0A1F3D) sobre fondos claros.
```

**Origen de los monocromos:** extracción por umbral de luminancia sobre la medalla original — se aísla el trazo metálico (ring + ondas) y se recolorea en plano único, eliminando el relleno navy interior. Válido para uso en escala reducida, marca de agua y aplicaciones de una tinta.

### 4.3 Reglas de uso

```text
No deformar el círculo.
No recortar el anillo metálico.
No recolorear las ondas fuera de plata/blanco sobre navy.
No aplicar sombras adicionales — el relieve metálico ya aporta profundidad.
No usar sobre fondos con bajo contraste.
Margen de seguridad mínimo: 20% del diámetro del círculo en todos los usos.
Tamaño mínimo legible: 24px de diámetro.
```

## 6. Tipografía

| Rol | Fuente | Pesos | Uso |
|---|---|---|---|
| Interfaz general y titulares | **DM Sans** | 400 / 600 / 800 | Navegación, botones, cards, formularios, texto general, titulares |
| Código / datos / señales | **JetBrains Mono** | 400 / 500 | Métricas, etiquetas técnicas, IDs, badges, datos operativos |

**Escala recomendada (landing):**

| Nivel | Tamaño | Peso | Tracking |
|---|---|---|---|
| Display (hero) | 48–72px (máx. 6rem) | 800 | −0.02em a −0.03em |
| H2 sección | 30–40px | 700–800 | −0.02em |
| H3 / card | 20–24px | 600 | 0 |
| Cuerpo | 16–18px | 400 | 0 |
| Secundario / caption | 13–14px | 400 | 0 |
| Dato / badge (mono) | 12–13px | 500 | +0.02em |

Reglas: no usar serif editorial en ningún titular de Anclora Group. La medida de cuerpo se mantiene en 65–75 caracteres. JetBrains Mono se reserva a datos, código y señales — nunca como recurso decorativo.

## 7. Tokens de espaciado, forma y movimiento

```css
:root {
  /* Espaciado (base 8) */
  --space-1: 8px;  --space-2: 16px; --space-3: 24px;
  --space-4: 32px; --space-6: 48px; --space-8: 64px; --space-12: 96px;
  /* Radio */
  --radius-control: 8px;   /* botones, inputs, badges */
  --radius-card: 14px;     /* cards y superficies (12–16px) */
  /* Movimiento */
  --ease-out: cubic-bezier(0.16, 1, 0.3, 1);
  --dur-fast: 160ms; --dur-base: 220ms;
  /* Elevación (una sola declaración: borde O sombra, no ambas) */
  --border-subtle: 1px solid rgba(229, 231, 235, 0.12);
}
```

Regla de ritmo vertical: más espacio encima de un encabezado que debajo; una sección densa se compensa con una tranquila.

## 15. Landing page — estructura recomendada (`anclora.com`)

1. **Header:** lockup horizontal, navegación (Ecosistema, Productos, Método, Founder, Contacto), selector de idioma, CTA compacto.

4. **Productos destacados:** los 5 de Nivel 1, con nombre, descripción de una línea, estado (MVP / piloto / activo / landing) y CTA contextual.
5. **Infraestructura:** Nexus, Command Center, Synergi, Data LAB — «bajo cada producto existe una capa operativa común: intake, datos, señales, automatización y control».

## 17. Do / Don't

**Do:** mostrar jerarquía, usar lenguaje claro, priorizar productos maduros, mostrar visión de ecosistema, usar el logo como sello de confianza, mantener estética premium sobria, explicar qué hace cada línea en una frase.

**Don't:** mostrar todas las apps, abusar de efectos visuales, prometer automatización total, llenar la landing de términos IA, convertir la página en un CV, mezclar la estética editorial de Insights con la estética matriz, hacer que todos los productos parezcan igual de maduros.
